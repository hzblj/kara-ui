# @hzblj/kara-native

The `KaraUI` Expo native module behind kara-ui — Liquid Glass, the iOS 26 scroll edge effect, a context menu with a React Native preview, native icons, a rich tooltip, a navigation bar, the Material 3 Expressive FAB menu, and SwiftUI/Compose modifiers — with its raw JS bindings (`/swift-ui`, `/jetpack-compose`).

**Install [`@hzblj/kara-ui`](https://www.npmjs.com/package/@hzblj/kara-ui) instead.** This package is one of its building
blocks, published so the umbrella can depend on it; it is versioned together with it and has no standalone docs.
