# @hzblj/kara-theme

Design tokens, the palette, typography and the theme behind kara-ui: platform colours by default (UIKit semantic colours on iOS, Material 3 roles on Android), overridable per app with `defineTheme`, plus `KaraProvider`.

**Install [`@hzblj/kara-ui`](https://www.npmjs.com/package/@hzblj/kara-ui) instead.** This package is one of its building
blocks, published so the umbrella can depend on it; it is versioned together with it and has no standalone docs.
